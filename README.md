# 弹幕猫 StreamCat

[English](README.en.md) · [国内 Windows 下载](https://streamcat.cn/download/) · [海外下载](https://streamcat.live/download/) · [89 项功能清单](docs/features.zh-CN.md) · [更新日志](CHANGELOG.md) · [反馈问题](https://github.com/Quill-00/streamcat-docs/issues)

弹幕猫是面向主播的 Windows 电脑直播互动助手。弹幕播报、礼物组件、互动转盘和直播画面都能在一个客户端里配置。

- **链式反应**：把弹幕关键词、礼物、进场等事件和场景、声音、视频串起来。比如指定礼物一到，先给倒计时加时，再切到答谢画面。
- **内置场景与调度**：在弹幕猫里布景、预览、按规则切场，无需另装一套场景工具来做这些事。也可以保留已有 OBS 布景并接入弹幕猫。实际开播按所用平台和推流工具的要求配置。
- **礼物和观众互动**：礼物组件、倒计时、抽奖、互动转盘、投票、答题和伴宠玩法，可以按节目自由组合。
- **画面与社群**：装扮中心、空间景深、场景滤镜、实时字幕、语音播报，以及将已绑定 QQ 粉丝群的消息独立上屏或并入弹幕。

国内站以抖音、B 站和小红书为主。具体事件支持与功能开放以客户端版本和接入平台为准。
