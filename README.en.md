# StreamCat

[简体中文](README.md) · [Download for Windows](https://streamcat.live/download/) · [Feature catalog (Chinese)](docs/features.zh-CN.md) · [Release notes](CHANGELOG.md) · [Report an issue](https://github.com/Quill-00/streamcat-docs/issues)

StreamCat is a Windows livestream toolkit for chat overlays, alert widgets, and interactive shows. It brings live chat, on-screen graphics, audience participation, and scene control into one desktop app.

- **Chain Reactions.** Turn a supported chat message, gift, or other event into a sequence of actions. For example, add time to an on-screen countdown, switch to a thank-you scene, and play a short clip.
- **Scene editor and automatic switching.** Build and preview portrait or landscape scenes, then switch on a schedule or in response to a rule. Use StreamCat for scene composition without OBS, or keep an existing OBS setup and connect StreamCat. Platform streaming and audio routing are handled by your streaming setup.
- **Interactive shows.** Mix alert widgets, countdowns, giveaways, wheels, polls, quizzes, and viewer pets to fit your show.
- **Visuals and chat.** Add speech announcements, live captions, overlay styles, scene filters, and depth-of-field effects. The full feature catalog also documents QQ fan-group chat integration for applicable setups.

The international edition is aimed at TikTok and YouTube creators. Event availability and feature access vary by platform and client version.

This repository contains public documentation and issue tracking only. **The Windows client is closed source.** Please use the official site for installers. Never include credentials, activation codes, or private data in public reports.
